# Motor Direction Control with LCD using PIC Microcontroller

## 📌 Project Overview
This project implements DC motor direction control using a PIC microcontroller. The motor direction is controlled using push buttons, while an LCD displays the motor direction and operating status.

## 🎯 Objective
To control the direction of a DC motor and display its real-time operating status using an LCD interfaced with a PIC microcontroller.

## 🛠️ Hardware Requirements
- PIC Microcontroller (PIC16F877A, if used)
- DC Motor
- LCD Display (16×2)
- Push Buttons
- Motor Driver / Relay Circuit
- Power Supply
- Connecting Wires

## 💻 Software Requirements
- MPLAB IDE
- MPLAB XC8 Compiler
- Proteus Design Suite

## ⚙️ Working Principle
1. Push buttons are used to select the motor direction.
2. The PIC microcontroller processes the button inputs.
3. The motor driver or relay circuit controls the motor direction.
4. The LCD displays the motor direction and operating status.
5. The motor stops when both direction buttons are pressed.

## 🔌 Main Features
- Forward motor direction control
- Reverse motor direction control
- LCD status indication
- Push-button-based operation
- PIC microcontroller interfacing
